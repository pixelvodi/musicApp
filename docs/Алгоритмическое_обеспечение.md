## 6. Схема воспроизведения музыки

### 6.1 Общая схема плеера

```
┌─────────────────────────────────────────┐
│       CustomMusicPlayer.tsx            │
└───────────────────┬─────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────┐
│  playMusic.tsx - функции плеера         │
├─────────────────────────────────────────┤
│  • fetchQueue(ids) - получить треки     │
│  • playQueue(tracks, startIndex)       │
│  • playOrStop() - пауза/воспроизведение │
│  • skipToNext()                         │
│  • skipToPrevious()                     │
│  • setOnTrackChange(cb)                 │
│  • setOnPlayStateChange(cb)             │
└─────────────────────────────────────────┘
```

### 6.2 Алгоритм воспроизведения очереди

```
START: playQueue(tracks, startIndex)
  │
  ▼
validTracks = tracks.filter(t => t.audioUrl)
  │
  ▼
IF validTracks.length === 0
  THEN return (нет треков)
  │
  ▼
formattedTracks = validTracks.map(track => ({
  id: track.id,
  url: track.audioUrl,
  title: track.title,
  artist: track.artist,
  artwork: track.artwork
}))
  │
  ▼
await TrackPlayer.reset()
  │
  ▼
await TrackPlayer.updateOptions({
  capabilities: [Play, Pause, SkipToNext,
                  SkipToPrevious, Stop, SeekTo],
  android: { appKilledPlaybackBehavior: ... }
})
  │
  ▼
await TrackPlayer.add(formattedTracks)
  │
  ▼
await TrackPlayer.skip(startIndex)
  │
  ▼
await TrackPlayer.play()
  │
  ▼
END
```

### 6.3 Алгоритм play/pause

```
START: playOrStop()
  │
  ▼
playbackState = await TrackPlayer.getPlaybackState()
  │
  ▼
IF playbackState.state === State.Playing
  THEN
    await TrackPlayer.pause()
    return { isPlaying: false }
  ELSE
    await TrackPlayer.play()
    return { isPlaying: true }
```

### 6.4 Алгоритм переключения трека

```
Слушатель: Event.PlaybackActiveTrackChanged
  │
  ▼
IF event.index !== undefined
  │
  ▼
callback(event.index)
  │
  ▼
Обновление UI: текущий трек, обложка, прогресс
```

## 7. Схема работы с данными

### 7.1 Загрузка избранного

```
Пользователь открывает Library
         │
         ▼
useLibraryLogic() вызывается
         │
         ▼
fetchFavorites()
         │
         ▼
GET /favoritesAlbum/{userId}
         │
         ▼
Сервер выполняет SQL:
  SELECT tracks.* FROM tracks
  JOIN favorites ON tracks.id = favorites.track_id
  WHERE favorites.user_id = {userId}
         │
         ▼
response.data = [FavoriteTrack]
         │
         ▼
setFavorites(response.data)
         │
         ▼
Render: отображение списка избранных
```

### 7.2 Сохранение избранного

```
Пользователь нажимает "like" на треке
         │
         ▼
POST /favorites/add
  body: { user_id, track_id }
         │
         ▼
Сервер выполняет SQL:
  INSERT INTO favorites (user_id, track_id)
  VALUES ({user_id}, {track_id})
         │
         ▼
Response: success
         │
         ▼
UI: обновление состояния кнопки "like"
```

## 10. API endpoints

| ---------- | ------------------------------------ | -------------------------------------------------------------- |
| GET        | `/albums`                          | Получить все альбомы                         |

## 11. База данных (SQLite)

### Основные таблицы

```sql
-- Пользователи
CREATE TABLE users (
  id INTEGER PRIMARY KEY,
  username TEXT,
  email TEXT,
  password TEXT,
  avatar TEXT
);

-- Треки
CREATE TABLE tracks (
  id INTEGER PRIMARY KEY,
  title TEXT,
  artist TEXT,
  filename TEXT,
  duration INTEGER,
  artwork TEXT
);

-- Альбомы
CREATE TABLE albums (
  id INTEGER PRIMARY KEY,
  name TEXT,
  imageUrl TEXT,
  artist TEXT
);

-- Артисты
CREATE TABLE artist (
  id INTEGER PRIMARY KEY,
  name TEXT,
  img_artist TEXT
);

-- Избранное
CREATE TABLE favorites (
  id INTEGER PRIMARY KEY,
  user_id INTEGER,
  track_id INTEGER
);
```
